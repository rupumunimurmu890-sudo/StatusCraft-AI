# ✨ StatusCraft AI

🔗 **Live Demo:** [statuscraft-ai.rupumunimurmu890.workers.dev](https://statuscraft-ai.rupumunimurmu890.workers.dev)

A global AI-powered status & quote creation platform — beautiful, multilingual, shareable quotes in seconds.

## ✨ Phase 1 (Current)

- 📱 PWA — installable, works offline
- 🌐 3 languages — Hindi, English, Hinglish
- 📂 5 categories — Motivational, Love, Friendship, Good Morning, Success
- 🎨 4 status templates — Purple Dream, Sunset Glow, Ocean Calm, Golden Hour
- 🙍 Add your name & photo to the status
- 📥 Download & 📤 Share

## 📂 Project Structure

\```
StatusCraft-AI/
├── index.html        # Main app UI
├── style.css          # Styling (warm journal-inspired theme)
├── app.js             # Quote logic + canvas status generation
├── quotes.json         # Curated quote database
├── manifest.json       # PWA manifest
├── sw.js               # Service worker (offline support)
├── icon.svg             # App icon
└── README.md
\```

## 🚀 Getting Started

This is a fully static site — no backend or build step required for Phase 1.

1. Host all files on any static host (Cloudflare Pages, GitHub Pages, Netlify, etc.)
2. Open `index.html` — that's it.

## 🗺️ Roadmap

- Phase 2 — AI: AI-generated unique quotes, feeling detection, auto image matching, translation, status remix
- Phase 3 — Content: Festivals, holidays, birthdays, verified religious/spiritual content, daily calendar content
- Phase 4 — Social: Social media packs, captions, hashtags, multiple aspect ratios, one-tap sharing
- Phase 5 — Advanced: AI video, AI voice, personal style, favorites, history, notifications
- Phase 6 — Monetization: Ads, premium, credits, affiliate features

## 🎯 Vision

Not just a "quotes app" — a global AI status & quote creation platform where a user picks a language, picks a feeling, gets a quote, gets a matching beautiful image, adds their photo/name, and downloads or shares — with fresh content every day.
