# Daily Status AI

A mobile-first PWA starter for daily Shayari, Quotes, Wishes and attractive status images.

## Current features
- Daily inspiration
- Hindi quote categories
- Custom name
- Canvas-based 9:16 status image
- Download
- Native share when supported
- PWA install support
- Offline cache

## Next planned features
- AI-generated unique daily quotes
- AI image backgrounds matching each quote
- Hindi + English + regional languages
- Verified religious-text library and separate spiritual inspiration section
- Saved history / favourites
- Templates
- WhatsApp / Instagram / Facebook / Telegram sharing
- User profile and name/logo
- Cloud database
